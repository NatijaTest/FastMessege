# FastMessage — что добавлено

## Как обновить
1. Замените файлы проекта файлами из этого архива (добавлен новый файл `stars.js`).
2. Firebase Console → Realtime Database → Rules → вставьте содержимое `database_rules.json` → Publish.
3. Войдите админом → вкладка «Админ» → «🎁 Подарки» → «Загрузить каталог».
   Пока каталог не загружен, покупка подарков отключена.

## Что нового
- **Звонки**: завершить звонок можно в любой момент (даже при плохой сети); при ошибке на экране показывается причина.
- **⭐ Fast Message Stars**: вкладка «Звёзды» — баланс, магазин (37 подарков), «Мои подарки».
- **Заработок**: 1 ⭐ за 3 минуты активности на сайте, максимум 100 ⭐ в сутки.
- **Открытие подарка**: маленький подарок → отсчёт 3-2-1 → огонь → большой подарок.
- **Самый дорогой подарок**: 🐸 Лягушка — 600 000 ⭐.
- **Админ**: начислить/задать баланс, подарить бесплатно, менять цены подарков, назначать и снимать модераторов, блокировать.
- **Модератор**: блокировать (кроме админов) и начислять звёзды. Менять имена/профили не может.

## Важно
- Звёзды выдаются админом/модератором и зарабатываются временем на сайте. Продажа за реальные деньги требует платёжного сервера.
- Защита работает через правила базы. Для максимальной надёжности в будущем лучше Cloud Functions.
- Подарки нарисованы эмодзи, названия собственные (без брендов и реальных людей).

## Дополнение
- **Бесплатный кейс**: один на аккаунт, открывается во вкладке «Звёзды». Шансы: 15 ⭐ — 70%, 25 ⭐ — 22%, 50 ⭐ — 6%, 100 ⭐ — 1,4%, 500 ⭐ — 0,5%, 1000 ⭐ — 0,1%. Дороже 1000 ⭐ из кейса не выпадает. Шансы меняются в `stars.js` (`CASE_ODDS`).
- **Покупка звёзд**: кнопка «Купить звёзды в Telegram» открывает @Guest5214 с готовым сообщением (имя и UID). Начислить звёзды: Админ → пользователь → «Начислить звёзды».
- Где что хранится в базе: баланс — `stars/{uid}`, подарки — `gifts/{uid}/{id}`, кейс — `cases/{uid}`, цены — `giftCatalog`.

## 💎 Premium
- Выдаёт только админ: «Админ» → пользователь → «💎 Выдать Premium» (указать число дней; повторная выдача продлевает). «💎 Снять Premium» отключает.
- Возможности: значок 💎 у имени; звёзды за время на сайте в 2 раза быстрее (1 ⭐ за 90 сек); лимит 200 ⭐ в сутки вместо 100; Premium-кейс раз в сутки (шансы лучше, потолок 2500 ⭐).
- Купить Premium: кнопка «Купить Premium в Telegram» (@Guest5214).
- Правила обновлены (узлы `premium`, `pcases`) — опубликуйте `database_rules.json` заново.

## 📦 Кейсы, продажа, права админа (обновление)
- **Первый кейс**: при первом входе каждому показывается кейс на весь экран (один раз на аккаунт, шансы как у «Обычного»).
- **Магазин кейсов** (вкладка «Кейсы»): Обычный — 200 ⭐, Нормальный — 500 ⭐, Удачный — 1000 ⭐ (много подарков около 500 ⭐ и 1% на 🐸 Лягушку).
- **Продажа подарков**: «Мои подарки» → «Продать» (80% цены подарка). Админ → «Подарки» может выключить продажу и убрать лягушку из «Удачного кейса».
- **Админ** может всё: правила дают админу полный доступ на чтение и запись (при условии, что формат данных соблюдён).
- После замены файлов: опубликуйте новый `database_rules.json`, затем «Админ → 🎁 Подарки → Загрузить каталог» (добавит кейсы), при необходимости «Пересоздать кейсы».
- Если действие отклонено, на экране показывается полный текст ошибки с путём в базе (например, `permission_denied at /cases/UID`). Пришлите его мне.

## Обновление: звонки, подарки, журнал
- **Звонки**: причина «Устанавливаем соединение… и сразу отключается» — в звонках не было TURN-сервера (только STUN), а в мобильных сетях прямое соединение часто невозможно. Добавлен бесплатный публичный TURN (Open Relay) в `calls.js` → `TURN_SERVERS`. Для постоянной работы заведите свой TURN (Metered / Twilio / coturn) и замените значения.
- **Новые подарки** (24 шт. по мотивам маркета): цены округлены до кратных 5 (нужно для продажи за 80%). Чтобы они появились в магазине: «Админ → 🎁 Подарки → Загрузить каталог».
- **Анимации подарков**: мишка просыпается (💤 → потягивается → прыгает → машет → засыпает), остальные подарки качаются, прыгают, светятся, взлетают и т. д. (классы `ga-*` в `style.css`, соответствие в `GIFT_ANIM` в `stars.js`).
- **Админ → 📜 Лог**: кто → кому, когда, тип (сообщение/звонок/подарок/действие админа). Пишутся только метаданные, текст личных сообщений не сохраняется. Узел `activityLog` читает только админ. Опубликуйте новый `database_rules.json`.

## 🎰 Открытие кейса (рулетка)
- Кейс открывается на весь экран: лента с подарками, золотой маркер по центру, кнопка «ОТКРЫТЬ», внизу — «Возможные подарки в кейсе».
- Лента замедляется и останавливается на выпавшем подарке (искры 🔥✨). В платных кейсах можно нажать «ОТКРЫТЬ ЕЩЁ».
- Работает для первого бесплатного кейса, кейсов из магазина и Premium-кейса.
- Цвет подписи подарка = редкость: серо-синий (обычный), синий (редкий), фиолетовый (эпичный), красный (легендарный).

## 🛠 Fayl yuborilmasligi (rasm/video/ovoz)

**Sabab topildi:** loyihada Firebase **Storage** qoidalari hali qo'yilmagan edi. Qoidasiz Storage hamma yozishni rad etadi, sayt esa "zaxira rejim"ga o'tib, faylni to'g'ridan-to'g'ri bazaga (RTDB) yozishga urinadi — bu rejim ~320 KB dan katta faylni qabul qilmaydi. Shuning uchun rasm hali-veri o'tgandek bo'ladi (kichkina bo'lsa), video va ovozli deyarli hech qachon o'tmaydi.

**Tuzatish — `storage.rules` fayli.** Uni qo'yish kerak:
1. Firebase Console → chap menyu → **Storage** → **Rules**.
2. `storage.rules` faylini oching, hammasini nusxalab, Firebase'dagi eski matn o'rniga qo'ying.
3. **Publish**.

Agar Storage hali umuman yoqilmagan bo'lsa, avval **Storage → Get started** tugmasini bosib yoqib oling (standart joylashuv va rejim bilan).
